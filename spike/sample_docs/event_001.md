# 출석 체크 이벤트 운영 프로세스

## 개요

출석 체크 이벤트는 플레이어의 매일 접속을 장려하기 위한 정기 이벤트입니다.
운영자가 게임 운영 콘솔에서 이벤트를 생성하면, 플레이어는 매일 게임에 접속하여
출석 체크를 수행할 수 있습니다. 누적 출석일에 따라 출석 보상이 단계별로 자동 지급됩니다.

## 담당자 및 역할

- **운영자**: 출석 체크 이벤트 생성, 보상 구성, 이벤트 기간 설정 및 종료 처리
- **플레이어**: 매일 접속하여 출석 체크 버튼을 클릭해 참여

## 프로세스 흐름

### 1단계: 이벤트 생성 (운영자)

운영자는 운영 콘솔에 로그인하여 새 출석 체크 이벤트를 생성합니다.
이벤트 기간, 최대 보상일 수, 일차별 보상 아이템 목록을 설정합니다.
설정 완료 후 이벤트를 활성화하면 플레이어에게 즉시 노출됩니다.

### 2단계: 출석 체크 (플레이어)

플레이어가 게임에 접속하여 이벤트 메뉴에서 출석 체크 버튼을 클릭합니다.
시스템은 해당 플레이어의 누적 출석일을 조회하고, 당일 출석 여부를 확인합니다.
당일 중복 출석은 허용되지 않으며, 오류 메시지가 반환됩니다.

### 3단계: 보상 지급 처리

출석이 확인되면 출석 체크 트랜잭션이 생성됩니다.
누적 출석일을 기준으로 해당 일차의 출석 보상 아이템이 결정됩니다.
보상 아이템은 플레이어 우편함으로 자동 지급되며, 유효 기간 내 수령해야 합니다.

### 4단계: 출석 로그 기록

모든 출석 체크 결과는 출석 로그에 저장됩니다.
출석 로그에는 플레이어 ID, 출석 일시, 누적 출석일, 지급된 보상 아이템 정보가 포함됩니다.
이 로그는 CS 문의 처리 및 이벤트 효과 분석에 활용됩니다.

## 예외 처리

- 당일 중복 출석 시도 시 처리 거부 후 오류 코드 반환
- 서버 오류 발생 시 트랜잭션 롤백 후 플레이어에게 재시도 안내
- 이벤트 종료 후 출석 체크 시도 시 이벤트 종료 메시지 반환

## 관련 시스템

출석 로그 데이터는 CS 처리 시 플레이어의 참여 이력 확인에 사용됩니다.
