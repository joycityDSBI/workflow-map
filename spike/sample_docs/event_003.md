# 이벤트 CS 처리 프로세스

## 개요

이벤트 CS(고객 지원) 처리는 플레이어가 이벤트 참여 중 발생한 문제를 신고하고,
CS 담당자가 이를 검토하여 적절한 조치를 취하는 프로세스입니다.
주요 이슈 유형으로는 이벤트 보상 미지급, 이벤트 참여 오류,
중복 차감 등이 있습니다.

## 담당자 및 역할

- **플레이어**: CS 티켓을 제출하고 문제 상황과 증거 자료를 첨부
- **CS 담당자**: 티켓을 접수하여 원인을 분석하고 처리 방식을 결정

## 프로세스 흐름

### 1단계: CS 티켓 접수

플레이어는 고객 지원 포털에서 CS 티켓을 제출합니다.
티켓에는 플레이어 ID, 이벤트명, 문제 발생 일시, 상세 문제 내용이 포함됩니다.
스크린샷 등 증거 자료를 첨부하면 처리 속도가 빨라집니다.

### 2단계: 원인 분석 (CS 담당자)

CS 담당자는 CS 티켓을 접수하고 이벤트 보상 이슈의 유형을 분류합니다.
출석 로그, 클리어 기록 등 관련 게임 데이터를 조회하여 문제 원인을 파악합니다.
이슈 유형은 운영 오류, 시스템 버그, 플레이어 오인 중 하나로 분류됩니다.

### 3단계: 처리 결정 및 실행

CS 담당자는 원인에 따라 처리 방식을 결정합니다.
보상 미지급이 확인된 경우 이슈 보상을 플레이어 우편함으로 수동 지급합니다.
운영 또는 시스템 오류로 인한 과금 문제 시 환불 처리를 진행합니다.
플레이어 오인인 경우 안내 답변만 발송합니다.

### 4단계: CS 처리 로그 기록

모든 처리 결과는 CS 처리 로그에 저장됩니다.
CS 처리 로그에는 티켓 ID, CS 담당자 ID, 처리 일시, 처리 유형,
지급 또는 환불 내역이 포함됩니다.

## 에스컬레이션 기준

- 동일 이슈가 대량 발생하는 경우 운영팀에 즉시 에스컬레이션
- 환불 금액이 기준치를 초과하는 경우 CS 팀장 승인 후 처리
- 반복 악용 의심 플레이어는 보안팀에 이관

## 관련 시스템

CS 처리 로그는 이슈 패턴 분석 및 운영 정책 개선에 활용됩니다.
